# Contributing

Open an issue to discuss a bug or proposed change. For a pull request, describe the user facing change, the checks you ran and any gaps. Keep examples free of private data.

The README explains how to set up the R runtime. From the repository root, run the R tests with:

```sh
Rscript --vanilla scripts/test.R
```

Run other relevant checks for the files you change. If you cannot run a check, say so in the pull request. Report suspected vulnerabilities privately as described in [SECURITY.md](SECURITY.md).
